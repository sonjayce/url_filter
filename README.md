# URL 批量过滤工具

一个高效的域名/URL 批量筛选工具，支持多规则过滤、并发处理、HTTP 状态码检测、多格式导入导出。

## 技术栈

- **后端**：Go 1.21+
- **前端**：HTML + CSS + JavaScript（Wails v2.13.0）
- **架构**：Wails v2（Web 前端 + Go 后端）
- **设计规范**：Hallmark（反 AI 垃圾设计原则）

## 快速开始

### 环境要求

- Go 1.21+
- Wails CLI v2.13.0+
- Node.js（前端开发用，运行已编译版本不需要）

### 编译

```powershell
cd D:\codex\Url_Filter_Wails\url-filter
go run github.com/wailsapp/wails/v2/cmd/wails@v2.13.0 build
```

编译产物位于 `build\bin\url-filter.exe`（约 13MB）。

### 运行

```powershell
.\build\bin\url-filter.exe
```

## 功能特性

- **基础过滤**：政府域名、黑名单、白名单、URL重复筛选、仅保留HOST
- **智能导入**：支持 TXT / CSV / XLSX 文件导入，使用标准 CSV 解析器处理引号和逗号；暂不支持旧式 XLS
- **状态码检测**：真实 HTTP 请求检测，区分 REFUSED / TIMEOUT / DNS_FAIL 等错误
- **并发处理**：可配置线程数
- **实时统计**：9 项指标实时更新
- **日志过滤**：支持「仅过滤」模式，只看被剔除的条目
- **多格式导出**：TXT / XLSX 导出，原生文件管理器保存
- **任务控制**：支持暂停、继续和取消正在执行的任务
- **配置持久化**：筛选规则、状态码、线程、超时和黑白名单保存到本地配置文件
- **智能识别**：自动去除 Markdown 标记、HTML 标签、引号、尾部标点等杂质
- **资产分拣页**：按分页切换到资产分拣，支持从混合资产文本中提取 URL、主域名、子域名、IPv4 和 C 段
- **内网过滤**：资产分拣支持过滤私有、回环、链路本地和未指定地址，并保持每类结果的输入顺序和去重

## 过滤规则（按优先级）

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 白名单 | 直接放行 |
| 2 | 政府域名 | 匹配 `.gov.cn`、`.gov`、`.government` |
| 3 | 黑名单 | 命中则过滤（自动提取 host，完整 URL 也支持） |
| 4 | 关键词 | 匹配域名中的关键词 |
| 5 | 状态码 | HTTP 状态码不在允许列表中则过滤 |
| 6 | 去重 | 最终结果去重 |

## HTTP 状态码说明

| 日志显示 | 含义 |
|---------|------|
| `200` / `301` / `404` 等 | 正常 HTTP 响应码 |
| `REFUSED` | 连接被拒绝 |
| `TIMEOUT` | 连接超时 |
| `DNS_FAIL` | DNS 解析失败 |
| `TLS_ERR` | SSL/TLS 证书错误 |
| `UNREACH` | 无路由到主机 |
| `ERR` | 其他未知错误 |

## 日志格式

启用状态码检测时：
```
[保留] [通过] [200] http://example.com
[过滤] [政府域名] [200] http://test.gov.cn
[过滤] [黑名单] [REFUSED] http://192.168.1.1:8080
[过滤] [关键词:test] [200] http://test.com
[过滤] [状态码:404] [404] http://example.com/404
[重复] [去重] [200] http://example.com
[无效] [格式错误] [-] xxx
[完成] 处理完成，保留 123 条
```

## 导入支持

| 格式 | 说明 |
|------|------|
| `.txt` | 每行一个 URL/域名，自动识别 |
| `.csv` | 跳过表头，按行解析 |
| `.xlsx` | 遍历所有 Sheet/单元格，智能提取 |

旧式 `.xls` 文件暂不支持，请先另存为 `.xlsx`。

导入时保留原始数据，仅做格式清理和去重。

## 导出支持

| 格式 | 说明 |
|------|------|
| `.txt` | 纯文本，每行一条结果 |
| `.xlsx` | Excel 表格，带表头「保留域名」|

导出时弹出原生文件管理器「另存为」对话框。

## 界面布局

- 左侧：筛选规则面板（固定侧边栏，分组设置）
- 右上：URL 输入区（支持导入文件）
- 右下：处理结果 + 处理日志（左右分割，日志支持仅过滤模式）
- 顶部：操作按钮栏（开始处理 / 暂停 / 继续 / 取消 / 导出TXT / 导出XLSX / 清空）
- 底部：实时统计栏（9 项指标）

## 设计

- Workbench 工作台布局（左侧固定侧边栏 + 右侧主工作区）
- 中性暖灰色调（#f5f4f0）+ 单色强调色（#c4501c 赭石橙）
- 无紫色渐变、无卡片套卡片、无 emoji
- 清晰的字体层级和间距系统
